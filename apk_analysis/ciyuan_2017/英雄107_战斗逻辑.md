# 英雄 107 三笠 —— 战斗逻辑

`ciyuan_2017` 中三笠的战斗机制。数据来自配置表（`skill_skillbase_c.dat` / `skill_skilllevel_c.dat` / `skill_skilllevel_lan_c.dat`），全部字段号由客户端原生库恢复，**不使用 2018 包的 `.proto`**（`SItem_Item` 等表在 2018 被重新编号）。

**一句话概括：三笠是一个靠"气体（怒气）"驱动的空中机动刺客**——用弹射钩爪把自己拉向地形并持续飞行，飞行途中用旋转斩击对周围造成可暴击的物理伤害，靠击杀回气维持滞空；大招进入"狂怒"状态，普通攻击变为范围伤害，远距离则改为冲锋。

---

## 一、两个描述表：哪个是玩家实际看到的

技能文本有两个来源，**内容不一致**，必须区分：

| 表 | 字段 | 记录数 | 客户端是否显示 |
|---|---|---:|---|
| `SSkill_SkillLevel` | `StrSkillUISkillInfo`（字段 49） | 938 | **否**（设计期文本） |
| `SSkill_SkillLevel_Lan` | `StrSkillUISkillInfo`（字段 4） | 1031 | **是**（玩家可见） |

判定依据：2017 的 `bat_skill_desc_ui.lua` 走 `JScript_HeroRepository_GetHeroSkillDescription(skillid, level)`，反汇编该函数（vaddr `0x26afb0`）可见它调用 `rawSkillLanTable::GetSkillLanInfo(skillid, level)`，随后 `AnsiToUtf8` 转码返回——**读的是 `_Lan` 表**。`hero_repository.lua` 注释亦写明"场外技能描述统一读取 skill=0 时的描述"，同样走这个接口。

两表对同一技能 ID 的描述出现明显分歧，例如 **2966**：

- 主表（设计期）："三笠更换合金刀刃，提升后续攻击20`(+{~127*00.20})`点物理伤害。刀刃在使用3次后断裂失效。"
- `_Lan`（玩家可见）："巨人追猎者如果在空中持续飞行，伤害会叠加，每次叠加6/7/8/9/10%(最多可叠加10层)"

技能名也不同（2962 主表叫"旋转斩击被动"、`_Lan` 叫"旋转斩击"；2968 主表叫"决死之心"、`_Lan` 叫"狂怒"）。**下文以 `_Lan` 为准，主表文本单独标注。**

> 另注：`_Lan` 文本里的英雄名是**巨人追猎者**（职业称号），而英雄显示名是**三笠**（`Name_sanli`）。

## 二、资源系统：气体（怒气）

三笠没有蓝条（`FBaseMP = 0`），资源是**怒气**，技能描述里称为**气体**。

| 机制 | 数值 | 出处 |
|---|---|---|
| 基础怒气上限 | 100 | `SHero.FBaseDander` |
| 大招被动提升上限 | +150 / 180 / 210 | 2968 `_Lan` 描述 |
| 击杀回复气体 | 16 / 20 / 24，助攻减半 | 2968 `_Lan` 描述 |
| 旋转斩击击杀野怪/小兵回复 | 1 点 | 2962 `_Lan` 描述 |
| 钩爪单次消耗 | **9 / 9 / 8 / 8 / 7**（随技能等级**递减**） | 3101 `NCostDander`（数值）与 `StrCostValue`（显示串）**双源一致** |
| 狂怒状态每秒消耗 | 4 | 2968 `NCostDander` |
| 其余 15 个技能 | 0 | 全部 `NCostDander` 为 0 |

技能的消耗类型 `StrCostType = 3` 即怒气——依据是 2017 `bat_skill_desc_ui.lua` 第 128 行的枚举注释：`1：魔法值；2：能量；3：怒气；4：生命值`。三笠所有技能的另一组消耗字段 `NCostMP` / `NCostEnergy` / `NCostXP` / `NCostMoney` **均为 0**，所以钩爪扣的确实只是怒气。

**钩爪消耗逐级明细**（两个字段交叉验证）：

| 技能等级 | 需英雄等级 | `NCostDander` | `StrCostValue` | 冷却 |
|---:|---:|---:|---|---:|
| 1 | 1 | 9 | `'9'` | 250 ms |
| 2 | 4 | 9 | `'9'` | 250 ms |
| 3 | 7 | 8 | `'8'` | 250 ms |
| 4 | 10 | 8 | `'8'` | 250 ms |
| 5 | 13 | 7 | `'7'` | 250 ms |

`3102 爪钩冲锋 type2` 是 0 消耗——它是钩爪命中后的冲锋位移，不单独收气。

> **手感推论**：基础怒气上限 100（`SHero.FBaseDander`），1 级满气只能放 **11 次钩爪**（100÷9）。回气靠击杀（大招被动 16/20/24，旋转斩击被动清野/清兵 +1），所以**前期撑不起持续滞空**，要等大招被动把上限拉到 150/180/210 才转得起来。这与"飞行中才有输出"的机制互相锁死：断气即落地，落地即无伤害。

**这条资源链解释了她的核心循环**：钩爪耗气 → 飞行中旋转斩击清野/清兵回气 → 维持滞空。没有击杀就断气落地。

## 三、技能逐个拆解（六个被本地化的技能）

### 3.1 普通攻击 2961

| 项 | 值 |
|---|---|
| 冷却 | 1600 ms |
| 射程 | 2.2 |
| 消耗 | 无 |
| 可作用目标 | `NObjectEnum = 3;6;7;9` |
| 动作 | `StrSkillAct = attack`，`NSkillDuration = 800` |
| 施法模式 | `StrCastType = casttype_singletarget` |

### 3.2 旋转斩击 2964（主动） / 2962（被动）

**玩家可见描述（`_Lan`，逐级）**：

> 巨人追猎者**在空中飞行时**会旋转挥刀刃对周围敌人造成 **55/80/105/130/155 + (0.5AD)** 物理伤害，击败野怪和小兵时回复 1 点气力值。该伤害**可以暴击，暴击时造成 150% 的伤害**。

| 项 | 值 |
|---|---|
| 冷却 | 主表描述写 1.6 秒 |
| 射程 / AoE | `FRange = 1.8`，`NAOENum = 99`（大范围） |
| 持续时间 | `NSkillDuration = 1000` ms |
| 动作 | `StrSkillAct = skill_02a`，播放速度 1000 |
| 伤害类型 | `NDamageType = 0` |
| 升级链 | 2964 的 `StrLevelUpBindSkill = 2965;2970` |

**子技能链**（这是三笠机制的骨架）：

```
2962 旋转斩击被动   ← 被动形态
2964 旋转斩击       ← 主动形态，Lv4/Lv5 绑定下面两个
 ├─ 2965 圆形斩-增强        （射程 2.1，NShowLogSkillIndex 指向 2964）
 └─ 2970 圆形斩-增强-回调伤害（NShowLogSkillIndex 指向 2964，NNegativeMe=8）
```

`NShowLogSkillIndex` 把子技能的战斗日志归并到父技能 2964——说明这几条记录在运行时是**一个技能的多段结算**，而不是玩家能分别点的技能。2965 / 2970 没有独立 UI 索引（`NSkillUIIndex = 1`/无），也印证这点。

`NDragtoNewSkill` 字段在 2964 上有值，与"升级后拖动技能图标会替换为新技能"的机制对应。

### 3.3 合金刀刃 2966

**玩家可见描述（`_Lan`）**：

> 巨人追猎者如果在**空中持续飞行，伤害会叠加**，每次叠加 6/7/8/9/10%（最多可叠加 **10 层**）。

**设计期描述（主表，机制不同）**：

> 三笠更换合金刀刃，提升后续攻击 20`(+{~127*00.20})` 点物理伤害。刀刃在使用 3 次后断裂失效。

| 项 | 值 |
|---|---|
| 冷却 | 3000 ms（主表描述写 2 秒） |
| 升级链 | `StrLevelUpBindSkill = 2967` |
| 子技能 | 2967 刀刃附加伤害，**30 个等级** |
| 伤害类型 | 0 |

**2967 有 30 级**，而三笠其他技能只有 3–5 级。其 `NMinLevel` 按 `1,4,7,10,13` 循环（每 5 级一轮，共 6 轮），说明这 30 条是**按玩家等级逐级查表的附加伤害**，不是可加点技能。`NSkillUIIndex = 99` 也表示它不出现在技能栏。

### 3.4 狂怒（决死之心）2968 —— 大招

**玩家可见描述（`_Lan`）**：

> 巨人追猎者的**气体上限增加至 150/180/210** 点；击杀敌人可回复 16/20/24 点气体，助攻回复一半。

**设计期描述（主表）**补足了主动效果：

> 被动效果：提升气体值上限 20/40/60。
> 主动效果：三笠失去冷静并对目标施以残酷打击，**普通攻击造成 120% 攻击力的范围伤害**；如果距离目标较远则会**向目标发起冲锋**并对沿途所有敌人造成 40/100/160`(+{~127*00.80})` 点物理伤害。**第一次冲锋消耗 20 气体，之后每次冲锋额外增加 10 气体消耗。**

| 项 | 值 |
|---|---|
| 冷却 | 4000 ms |
| 怒气消耗 | `NCostDander = 4`（每秒） |
| 所需等级 | 5 / 10 / 15 |
| 语音 | `Voice = sanli/dazhao_1`（大招语音） |
| 触发概率 | `Probability = 1.0` |
| 升级链 | `StrLevelUpBindSkill = 2969;2971;2975` |

**子技能链**：

```
2968 狂怒（大招）
 ├─ 2969 冷静              （NActiveType=1）
 ├─ 2971 狂怒冲锋-回调伤害   （NNegativeMe=8）
 └─ 2975 狂怒斩击           （NAOENum=99，范围；NCommonAttack=1）
2973 狂怒冲锋-type2-超目标冲锋固定距离
     （CD 1600ms、蓝耗 100、NDamageType=1、射程 7.0、FSpeed 15）
```

2968 的 `NActiveType = 4`，而 2969 / 2980 的 `NActiveType = 1`——说明 2968 是"开/关"型状态技能，2969"冷静"是关闭它的那一半（大招开关）。`2975 狂怒斩击` 带 `NCommonAttack = 1`，对应描述里"普通攻击造成 120% 攻击力的范围伤害"。

### 3.5 弹射钩爪 3101 / 3103 —— 机动核心

**玩家可见描述（`_Lan`）**：

> 朝目标方向发射出钩爪，钩爪碰到**建筑物或地形**会将自身拉过去；**飞行途中再次发射钩爪可改变飞行轨迹**。

| 项 | 值 |
|---|---|
| 冷却 | **250 ms**（`_Lan` 写作 `0.250000`） |
| 怒气消耗 | 9 / 9 / 8 / 8 / 7 |
| 射程 | **16.0**（普攻的 7 倍） |
| 等级数 | 5 |
| 伤害类型 | 0 |
| 施法失败条件 | `NNegativeMe = 1724` |

3103 是"无前摇"版本（同名"弹射钩爪"，`NMinLevel` 与 3101 一致），3102 是 **type2**：`NSkillType = 15`、`FSpeed = 15`、`NFlyTime = 5`、射程 10.0——即钩爪命中后的**冲锋位移**。

这与资源侧完全对应：特效目录 `model/effect/skill/107_sanli/s03_gouzhua/` 下有 `fire` / `trace` / `keep` 三组，模型 `107.x2` 就是钩爪飞行姿态。

## 四、伤害公式：写在描述里的系数

2017 的技能表**没有** `NFormulaID` 与 `NDamageCoefficient*` 字段（2050 条记录中 0 次出现，见[伤害公式还原](../伤害公式还原.md)）。但**公式以占位符形式嵌在描述文本里**：

```
三笠用身体带动刀刃高速旋转，对周围敌人造成40(+{~30*00.50})点物理伤害。
```

格式为 `{~<属性ID>*<系数>}`：

| 占位符 | 出现次数 | 含义 |
|---|---:|---|
| `{~30*00.50}` | 142 | 0.50 × **属性 30（物理攻击）** |
| `{~127*01.00}` | 71 | 1.00 × **属性 127（未知）** |
| `{~31*00.60}` | 21 | 0.60 × **属性 31（魔法强度）** |
| `{~30*01.80}` | 3 | 1.80 × 物理攻击 |

全表只用 30 / 31 / 127 三个 ID。**30 与 31 的含义有双重独立验证**：客户端 `gamedef.lua` 里写着 `Attr_PhysicsAttackMax = 30`、`Attr_MagicAttack = 31`；而 `_Lan` 表把同一技能写作 `(0.5AD)`——**与 `{~30*00.50}` 完全对应**。

属性 127 **不在** `gamedef.lua` 的 37 个 `Attr_*` 常量里，也不在我从符文/天赋表恢复的 24 个属性 ID 中，含义未定（出现场景全部是物理伤害，疑似"额外物理攻击"或某个装备加成的独立通道）。

> **重要限定**：这些带 `{~}` 的文本出自**主表**（设计期），而客户端显示的是 `_Lan` 表。所以 `{~127*...}` 属于**设计意图记录**，不是运行时公式。但它对理解机制有价值——`_Lan` 的 `(0.5AD)` 与主表 `{~30*00.50}` 一致，说明两表同源，只是 `_Lan` 把占位符换成了人话。

## 五、完整连招逻辑（据以上字段复原）

```
开局：怒气 100（大招被动后上限 210）

[位移] 弹射钩爪 3101/3103  ── 耗气 9/7，CD 0.25s，射程 16
        │  钩中建筑/地形 → 把自己拉过去
        │  飞行途中再按 → 改变轨迹（多段空中机动）
        ↓
[输出] 旋转斩击 2964       ── 飞行中对周围造成 55~155 + 0.5AD 物理
        │  可暴击（150%）
        │  升级后自动替换为 2965 圆形斩-增强（含 2970 回调伤害）
        │  击杀野怪/小兵 → 回气 1
        ↓
[续航] 靠击杀回气维持滞空；合金刀刃 2966 使持续飞行时伤害叠加
        （每层 +6%~10%，最多 10 层）

[爆发] 狂怒 2968           ── CD 4s，每秒耗气 4
        │  远距离 → 向目标冲锋，沿途 40/100/160 + 0.8AD 物理
        │  第一次冲锋耗气 20，之后每次 +10
        │  普攻变为 120% 攻击力的范围伤害
        └  2969 冷静 = 关闭状态
```

**机制上的关键点**：三笠的输出窗口绑定在"飞行中"——旋转斩击的 `_Lan` 描述明确限定"在空中飞行时"，合金刀刃的叠层也要求"持续飞行"。所以钩爪不是单纯的位移，而是**开火的前置条件**。这个设计在资源侧也有对应：`107.x2`（飞行姿态模型）与 `s03_gouzhua`（钩爪特效）长期驻留。

## 六、与他人/环境的交互字段

| 字段 | 值 | 说明 |
|---|---|---|
| `NNegativeMe` | 2961→2981、2964/2965→1244、2966/2968/2969/2980→1245、2973→1865、2975→1492、2979→1864、3101/3103→1724 | 施法失败原因外键，指向 `skill_negativeme_c.dat`（138 条） |
| `NObjectEnum` | 2961 = `3;6;7;9` | 普攻可作用的目标类型集合 |
| `NAOENum` | 2964/2965/2975 = 99 | 大范围 AoE 标记 |
| `NAutoBatType` | 全部 17 个技能 = 1 | 自动战斗类型 |
| `NNotAffectByCoolDownMinus` | 2962/2964/2965/2966/3101/3102/3103 = 1 | 这些技能**不受冷却缩减影响** |
| `NDefaultMe` | 2964/2965/2966/2968/2969/2980 = 1；3101/3103 = 6 | 默认自身效果标记 |
| `StrUseSkillMsg` | 全部 2050 条 = `"test"` | 开发期占位符，**非有效数据** |

`NNotAffectByCoolDownMinus = 1` 值得注意：三笠的钩爪（CD 0.25s）与旋转斩击不吃冷却缩减，说明她的机动频率是被策划**硬性锁定**的，不会因为出冷却装而无限飞。

## 八、未解

- **属性 127 的含义未定**：不在 `gamedef.lua` 的 37 个 `Attr_*` 常量中，也不在符文/天赋表恢复的 24 个属性 ID 中；仅出现在物理伤害描述里。
- **主表与 `_Lan` 表对 2966 描述的是两套不同机制**（"3 次后断裂" vs "飞行叠层"），无法从静态数据判断哪套在 2017 版本真正生效——已知客户端**显示** `_Lan`，但服务端按哪套结算不可知。
- **`StrSkillUISkillInfo` 里的 `[32` / `[33` / `[34` 前缀**（出现在冷却描述之前）未能解释；它随技能的 `NSkillUIIndex` 递增，疑似某种 UI 槽位标记，但格式不明。
- **`{~...}` 占位符的代入实现未找到**：2017 的 Lua 里没有解析代码，反汇编 `GetHeroSkillDescription` 只做取串与转码；若客户端真的会代入数值，实现应在字体渲染层，未继续追。
- **`NObjectEnum` 的取值语义未定**（`3;6;7;9` 对应的目标类型表未找到）。
- **大招"狂怒"的关闭流程未完全确认**：2969"冷静"的 `NActiveType = 1` 与 2968 的 `4` 互补，但没有找到显式的状态绑定字段（`NBindStatus` 在这两个技能上均为 0）。
